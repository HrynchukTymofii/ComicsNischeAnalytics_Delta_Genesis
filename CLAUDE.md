Commands: `make registry`, `make audit`, `make catalog`, `make build-data` (runs metrics + intel), `make intel`,
`make web`, `make mcp`, `make test`. No `make` on this machine: `cd pipeline && ../.venv/Scripts/python -m comics_pipeline <cmd>`.

## Hard rules — do not violate

1. **Never delete raw files.** Nothing under `data/raw/` is deleted, overwritten or edited.
   Duplicates may only be *moved* to `data/raw/_duplicates/`, and files renamed, only after the user
   confirmed the plan in conversation: `python -m comics_pipeline audit --apply-plan --confirmed`.
   Files to ignore go into `exclude_files` in `source_config.json` (by MD5) — they are not moved.
2. **All Sensor Tower revenue is NET** (after Apple/Google fees): column `revenue_net`.
   Gross exists only as an *estimated range* `net/0.85 … net/0.70` (`revenue_gross_low/high`) and is
   always labelled as an estimate. Never add net and gross together.
3. **Every number in the UI states period, region and net/gross** (`<Metric>` / `metricLabel()` in
   `web/lib/labels.ts`, props required by type). Same for chart titles/tooltips and every MCP response
   (`period`, `region`, `revenue_basis`).
4. **Monthly and weekly/daily data for the same app+month are never summed together.**
   Per app+month the build keeps one granularity — `monthly > weekly > daily` — and drops the rest
   (counted in `build_report.json`). `assert_single_granularity()` guards this; keep its tests green.
   Weekly values are **split across months by days** (1/7 per day; user decision 2026-10-15) so
   4- vs 5-week months don't create fake ±25% spikes. The week of Mon 2025-12-29 puts 3/7 into
   December (dropped there — December has monthly data) and 4/7 into January.
5. **Sources are never merged into one number** (Sensor Tower vs AppKittie/AppMagic/Genesis):
   side by side, labelled with the source. Other-source values are snapshots with `source`, `as_of`,
   `revenue_basis` (net | null = not stated) and `bound` (point | lower); AppMagic is always shown as "≥ $X".
   Summing within one source (AppKittie App Store + Google Play) is fine and labelled as such.

## Data facts worth knowing

- **Other sources** (user decisions 2026-10-16): AppKittie revenue is **net** (user's belief, not verified —
  `source_config.json`); AppMagic basis unknown (lower bounds only). Google Play review texts may be published
  on the site. Ad creatives are **downloaded** (not hotlinked). New apps found in AppKittie / the workbook go into
  `extra_apps.csv`. `GP_відгуки_усі-3-застосунки` = union of the 3 per-app files → excluded by MD5.
- The Sensor Tower path only reads files whose header has "Unified ID" (`st_io.is_st_export`); everything else
  in data/raw is for `make intel`. A new kind of file needs a route in `intel.ROUTES` (unknown files are reported).
- The free-services workbook is a human-made report: tables are found by header text (`free_services.table`);
  a renamed header raises `LayoutError` instead of silently shifting columns.

- **Video formats are excluded by default** (user decision 2026-10-15): short_drama (ReelShort, DramaBox)
  and ai_comic_drama (MoboDrama) are video, not image comics, and dwarf the comics numbers. The «Відео-формати»
  toggle was removed (user decision 2026-10-16): dashboards never include them, but the data is kept (catalog,
  app pages); MCP `total_market(include_video=False)`.

- Sensor Tower "Revenue" and "Downloads" exports are the same file (both metrics in each).
- US daily files 13–30.09.2026 are a separate `us_snapshot` (run-rate = sum × 365/18), never in monthly.
- "World" = sum of the countries in the export (up to 112; Shonen Jump has only 39).
- Regions (world / us / tier1) are defined once in `data/catalog/regions.json` and used by the pipeline,
  metrics and MCP server; Tier-1 = 20 countries (list in that file, user may edit it).
- Revenue can be $0 for years where Sensor Tower has downloads but no revenue estimate
  (WEBTOON before 2019) — that is missing data, not zero revenue; use the first month with revenue.
- Months after the cutoff (last complete month) are dropped; `partial` marks incomplete months.
- Overlapping exports: identical rows are de-duplicated; same key with different values is a hard
  error — ask the user, don't pick one.
- The iTunes API and pip need the Windows certificate store here (`truststore`, injected in `__main__`).
- Money is USD; months are `YYYY-MM`; Ukrainian UI labels.
